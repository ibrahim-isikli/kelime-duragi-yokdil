# YÖKDİL Cep Koçu (PWA)

YÖKDİL kelime kartları, test, gramer ve sözlük. Telefona "Ana ekrana ekle" ile kurulur, internetsiz çalışır.

- Uygulama tek dosya: `index.html` (veri, yazı tipleri ve kod içinde).
- `sw.js` çevrimdışı önbellek; `manifest.webmanifest` kurulum bilgisi.
- Güncelleme: `yokdil-cep-kocu.html` değişince `python3 build.py` çalıştırılır.

Kelime ve gramer listeleri "Doğru Cevap" YÖKDİL listelerinden derlenmiştir; kaynak sahibinin izni olmadan herkese açık ya da ticari kullanım için uygun değildir. Örnek cümleler yapay zekâ yardımıyla üretilmiştir.
